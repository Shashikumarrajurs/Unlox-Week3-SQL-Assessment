# Unlox-Week3-SQL-Assessment
SQL Foundations project using MySQL and MySQL Workbench, covering SELECT, filtering, sorting, aggregate functions, GROUP BY, HAVING, NULL handling, COALESCE, CASE WHEN, and data analysis on an e-commerce products dataset.
# Unlox Academy - Week 3 SQL Assessment

A SQL Foundations project completed as part of the Unlox Academy DA/DS Track.

## Database

MySQL

## Dataset

Flipcart products dataset containing product information such as:

- Product Name
- Category
- Brand
- Price
- Stock Quantity
- Active Status
- Launch Date
- Average Rating
- Discount Percentage

## SQL Concepts Practiced

- SELECT
- WHERE
- ORDER BY
- IN
- BETWEEN
- LIKE
- DISTINCT
- Aggregate Functions
- GROUP BY
- HAVING
- LIMIT
- NULL Handling
- COALESCE
- CASE WHEN

## Tools Used

- MySQL
- MySQL Workbench
